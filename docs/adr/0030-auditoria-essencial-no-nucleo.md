# Manter auditoria essencial no núcleo aberto

A Edição Comunitária criará Registros de Auditoria para autenticação, dispositivos, membros, Conexões de Mensageria, campanhas, importações, exclusões, configurações, backups e tokens de integração. Busca avançada, exportação extensa, retenção prolongada e garantias antiviolação poderão ser Recursos Comerciais, mas a operação básica nunca ficará sem rastreabilidade.
