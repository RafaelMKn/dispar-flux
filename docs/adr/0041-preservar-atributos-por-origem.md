# Preservar atributos por origem

Importações guardarão seus valores na Participação na Base, e dados do WhatsApp permanecerão associados ao Conector de Mensageria. Apenas uma edição deliberada de membro alterará o Perfil Canônico do Contato; a interface poderá usar fallbacks quando ele estiver vazio, mas nenhuma fonte sobrescreverá silenciosamente as demais.
