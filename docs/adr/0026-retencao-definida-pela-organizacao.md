# Exigir política de retenção da organização

O onboarding exigirá que o Proprietário escolha uma Política de Retenção com prazos separados para mensagens, mídias e logs. Opt-outs terão ciclo de vida próprio para que a remoção de histórico não volte a tornar um destinatário elegível para disparo; a interface apresentará sugestões sem presumir uma base legal universal.
