# Criar um repositório novo para a plataforma web

A plataforma web será construída em um repositório novo e limpo, enquanto o repositório atual permanecerá congelado para correções críticas, releases do Aplicativo Legado e produção do Pacote de Migração. A migração por fatias verticais reaproveitará seletivamente domínio, contratos, testes e interface sem carregar a estrutura Electron como fundação do servidor.
