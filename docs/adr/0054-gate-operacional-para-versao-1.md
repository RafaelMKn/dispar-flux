# Exigir gate operacional para a versão 1.0

A plataforma web só será chamada de `1.0` depois de validar comportamentos compartilhados, fluxos E2E críticos, migração com dados e mídias reais, backup e restore, recuperação de crash sem duplicação, imagens `amd64` e `arm64`, segurança, licenças e um período controlado de uso real. Publicar uma imagem funcional ou concluir validação manual não será suficiente.
