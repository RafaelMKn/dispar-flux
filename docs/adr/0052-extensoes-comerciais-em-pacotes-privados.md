# Manter extensões comerciais em pacotes privados

Recursos Comerciais viverão em pacotes privados que consomem uma API pública e versionada de extensões do núcleo e produzem uma imagem Enterprise separada. O núcleo AGPLv3 permanecerá compilável e funcional sem esses pacotes, evitando tanto código proprietário no repositório público quanto um fork comercial permanente.
