# Arquivar o desktop após a janela de transição

O Aplicativo Legado terá aviso mínimo de 90 dias após a versão web `1.0` e permanecerá suportado durante pelo menos duas versões web estáveis. Ao fim da janela, seu repositório será arquivado no GitHub com commits, tags, releases e documentação preservados; cópias locais só poderão ser removidas depois dessa verificação.
