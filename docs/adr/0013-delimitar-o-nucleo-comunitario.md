# Delimitar o núcleo comunitário completo

A Edição Comunitária oferecerá paridade com o Aplicativo Legado, acesso por Proprietário e Operadores, uma Conexão de Mensageria ativa e backup local. Múltiplas conexões, permissões granulares, SSO, auditoria avançada, backup externo gerenciado e gestão centralizada de Instalações serão Recursos Comerciais; webhooks básicos permanecerão no núcleo para favorecer integrações abertas.

## Consequences

O núcleo não poderá depender dos módulos comerciais para operar de ponta a ponta. As extensões comerciais usarão contratos explícitos e serão empacotadas separadamente da distribuição AGPLv3.
