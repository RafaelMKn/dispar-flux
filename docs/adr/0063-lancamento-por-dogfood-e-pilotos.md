# Lançar por dogfood e pilotos controlados

O caminho para a versão web `1.0` começará com a migração de uma Instalação real do próprio mantenedor, seguirá com duas ou três Organizações piloto e então avançará para release candidate. O release estável dependerá do gate operacional já definido e de uma restauração real ensaiada, sem beta público prematuro.
