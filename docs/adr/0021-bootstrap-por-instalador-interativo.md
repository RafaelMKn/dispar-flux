# Oferecer bootstrap por instalador interativo

A implantação comunitária de referência usará um `install.sh` interativo para coletar domínio, Fuso Operacional e diretório de dados, gerar segredos, configurar Docker Compose e Caddy, fixar a versão da imagem e apresentar o código de reivindicação inicial. A instalação manual por Compose permanecerá documentada e suportada.
