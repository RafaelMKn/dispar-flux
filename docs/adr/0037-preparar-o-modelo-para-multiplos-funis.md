# Preparar o modelo para múltiplos funis

A primeira versão web exibirá um Funil por Organização para manter paridade com o Aplicativo Legado, mas etapas e Leads identificarão o Funil a que pertencem desde o novo schema. Múltiplos Funis poderão ser habilitados posteriormente como Recurso Comercial sem uma migração estrutural do CRM.
