# Permitir múltiplos proprietários

Uma Organização poderá ter um ou mais Proprietários e nunca poderá remover ou rebaixar o último. Qualquer Proprietário em Dispositivo Autorizado poderá aprovar acessos; se nenhum dispositivo estiver disponível, um comando executado no servidor gerará um código curto de recuperação sem apagar contas ou desativar permanentemente a proteção.
